# Шёпот 🎙️

Голосовой ввод текста на macOS через **OpenAI Whisper**. Зажми правый ⌥, говори — отпусти, и текст появится там, где стоит курсор. Всё работает локально, без интернета и облаков.

**[⬇ Скачать Шёпот (dmg)](https://github.com/Emileminov/shepot/releases/latest/download/Shepot.dmg)**

## Возможности
- Hold-to-talk: зажимаешь **правый ⌥ (Option)**, говоришь, отпускаешь — текст вставляется в активное приложение.
- Распознавание Whisper `large-v3-turbo` (whisper.cpp, Metal) — точно и быстро, русский и английский.
- Четыре красивые анимации: шар в капсуле, волны Siri, эквалайзер, шар Siri.
- Настройки: стиль, прозрачность, размер, язык.
- Подписано Developer ID и нотаризовано Apple.

## Установка
1. Открой dmg, перетащи «Шёпот» в «Программы», запусти.
2. При первом запуске приложение само скачает модель Whisper (~1,6 ГБ) — прогресс виден на экране.
3. Разреши: **Микрофон**, **Универсальный доступ**, **Мониторинг ввода** (Системные настройки → Конфиденциальность и безопасность).

Требуется macOS 13+ и Mac на Apple Silicon.

## Сборка из исходников
```bash
brew install whisper-cpp          # нужен для упаковки whisper внутрь приложения
./release.sh                      # сборка, подпись Developer ID, нотаризация, Shepot.dmg
```
Иконка рисуется скриптом `icon/make_icon.swift`.

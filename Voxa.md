# Voxa 🎙️

Приложение для macOS: зажимаешь клавишу, говоришь, отпускаешь, и текст вставляется туда, где стоит курсор. Распознавание локальное через **OpenAI Whisper** (whisper.cpp, Metal), без интернета и облаков. Красивые анимации-индикаторы в стиле Siri.

## Как пользоваться
- **Зажми правый ⌥ (Option)**, говори, отпусти. Текст вставится в активное приложение, прежний буфер обмена восстановится.
- Запасной вариант: **⌃⌥Пробел** (нажал: запись, нажал ещё раз: стоп). Работает без права «Мониторинг ввода».
- Иконка в менюбаре: «Начать запись», «Настройки…», «Скопировать диагностику», «Выйти».
- При первом запуске приложение само скачивает модель `large-v3-turbo` (~1,6 ГБ), прогресс виден в индикаторе.

## Настройки
- **Вид анимации (4 стиля):** шар в капсуле, волны Siri, эквалайзер, шар Siri.
- **Прозрачность** (15–100%) и **размер** (50–140%).
- **Положение** индикатора: сетка 3×3 (углы, края, центр).
- **Живой предпросмотр:** при смене стиля, размера, прозрачности или положения индикатор сам появляется на экране на пару секунд.
- **Микрофон:** выбор устройства и живая полоска уровня (микрофон включается только пока окно настроек активно).
- **Язык:** авто / русский / English.
- **Разрешения:** три пункта со статусом и кнопкой «Выдать». В меню показываются только недостающие.
- **Запуск при входе в систему:** тумблер.

## Разрешения (выдаются один раз)
1. **Микрофон**: слышать голос.
2. **Универсальный доступ**: вставлять текст (Cmd+V).
3. **Мониторинг ввода**: ловить правый ⌥.

Сбросить все права из терминала:

```bash
tccutil reset All com.emil.diktovka
```

Идентификатор `com.emil.diktovka` остался от первого названия. Менять его нельзя: слетят разрешения.

## Как устроено
- Один файл `main.swift` (Swift, SwiftUI + AppKit), без Xcode-проекта, собирается через `swiftc`.
- **Захват звука:** `AVCaptureSession`, звук сразу запрашивается как 16 кГц моно float. Выбранный микрофон подключается напрямую.
- **Расшифровка:** упакованный внутрь `.app` `whisper-cli` (+ libwhisper, libggml, libomp) запускается как процесс. Модель лежит в `~/Library/Application Support/Voxa/`.
- **Вставка:** текст в буфер обмена, затем эмуляция Cmd+V, потом буфер восстанавливается.
- **Индикатор:** прозрачное окно `NSPanel` поверх всего, внутри SwiftUI (`Canvas` и `TimelineView`).
- **Хоткеи:** глобальный монитор клавиши правый ⌥ (нужен «Мониторинг ввода») + Carbon-хоткей ⌃⌥Пробел (без прав).
- **Страховки:** таймаут расшифровки 90 с, автостоп записи через 3 мин или если ⌥ отпущен, а событие потерялось, откат на системный микрофон, если выбранный молчит, фильтр «галлюцинаций» Whisper («Редактор субтитров…» и т.п.).

## Сборка и релиз
Из папки проекта:

```bash
brew install whisper-cpp   # нужен один раз, откуда берётся whisper-cli для упаковки
./release.sh               # сборка, подпись Developer ID, нотаризация, Voxa.dmg
```

- Профиль нотаризации в связке ключей: `launchpad-notary` (тот же, что у Launchpad Classic и StreamRecord).
- `whisper.entitlements` нужен вложенному `whisper-cli`: без него Metal не подгружается и расшифровка идёт на CPU (очень медленно).
- Релиз на GitHub: `gh release create vX.Y Voxa.dmg --repo Emileminov/voxa`.
- Иконка рисуется скриптами `icon/make_icon.swift`, `icon/make_variants*.swift`. Текущая иконка — вариант H (сфера Siri с волнами).

## Грабли, на которые уже наступили
- **Зависание расшифровки:** упакованный whisper без нужных entitlements не видел GPU. Решено отдельными entitlements для `whisper-cli`.
- **Выбор микрофона через AVAudioEngine** ломал запуск молча. Решено переходом на `AVCaptureSession`.
- **Микрофоны с нестандартным форматом** (iPhone, USB) давали ноль кадров. Решено фиксацией формата вывода 16 кГц моно.
- **Индикатор микрофона в менюбаре горел постоянно:** таймер в окне настроек перезапускал измеритель уровня. Теперь измеритель живёт только пока окно активно.
- **Разрешения слетают при смене подписи.** С Developer ID больше не слетают.
- **На втором компе «нет индикации»:** обычно не выдан «Мониторинг ввода». Помогает ⌃⌥Пробел или выдача права по порядку из меню.
- Если что-то не работает: меню, «Скопировать диагностику», и прислать текст. Там версия, права, микрофон, статус хоткеев и последние события.
